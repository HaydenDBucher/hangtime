# Hangtime investor pitch

Live deck: `https://haydendbucher.github.io/hangtime-pitch/`

## Edit without changing the submitted link

1. Open `index.html` on GitHub.
2. Select the pencil icon, or use the **Edit** button in the live deck.
3. Change the wording or numbers.
4. Select **Commit changes**.
5. Wait about one minute and refresh the same live URL.

The URL stays unchanged after every edit.

## Present

- Right arrow, Page Down, or Space: next slide
- Left arrow or Page Up: previous slide
- Home/End: first/last slide
- N: speaker notes
- Browser print: PDF backup (landscape layout is built in)

## Truth labels

- Green: observed evidence or a published fact
- Red: an internal assumption or hypothesis
- Blue: a calculation
- Yellow: a future target

The deck intentionally avoids describing modeled product data or financial scenarios as actual traction.
