# Hangtime venture submission kit

This folder turns the current Hangtime MVP and the evidence collected so far into a submission-ready package. Start with the rubric narrative, rehearse the demo, then replace every bracketed field in the evidence and ownership files before submitting.

## Submission order

1. [Rubric narrative](RUBRIC_SUBMISSION.md) — the written venture case, organized by grading category.
2. [One-page summary](ONE_PAGE_SUMMARY.md) — the concise handout or executive summary.
3. [Pitch deck](../public/pitch-deck.html) — a 12-slide, browser-based presentation. On the deployed site it lives at `/hangtime/pitch-deck.html`.
4. [Demo script](DEMO_SCRIPT.md) — a 90-second path and a 5-minute judged-demo path.
5. [Hypotheses and experiments](EXPERIMENT_PLAN.md) — falsifiable tests, thresholds, and kill criteria.
6. [User research](USER_RESEARCH.md), [interview guide](INTERVIEW_GUIDE.md), and [pilot scorecard](PILOT_SCORECARD.csv) — evidence collection materials.
7. [Venture economics](VENTURE_ECONOMICS.md), [scenario model](venture_economics.csv), and [venue LOI](VENUE_PILOT_LOI.md) — payer test materials.
8. [Build, candor, and ownership](BUILD_AND_OWNERSHIP.md) — architecture, revision history, limitations, and responsibility.
9. [Evidence log](EVIDENCE_LOG.csv) — the source of truth for future interviews and tests.
10. [Final checklist](RUBRIC_CHECKLIST.md) — missing proof to fill before submission.

## Evidence rule

Modeled prototype data, planned experiments, and unverified assumptions are labeled as such throughout this kit. Do not replace them with claims of traction unless the result has been recorded in `EVIDENCE_LOG.csv` with a date, sample, method, and artifact.
