# Final submission checklist

The product and core narrative are ready. The unchecked items require real team information or evidence and must not be fabricated.

## Customer, pain, payer — 15%

- [x] Narrow beachhead user and decision moment defined.
- [x] Existing workaround and cost described.
- [x] Economic buyer and value proposition identified.
- [ ] Add one quantified pain measure from interviews, such as average decision time or number of apps checked.
- [ ] Add one venue quote confirming its acquisition or promotion problem.

## Hypothesis and honest test — 20%

- [x] Four falsifiable hypotheses written.
- [x] Pass, partial, fail, and stop thresholds set before testing.
- [x] Comparison condition and task specified.
- [x] Friendly-feedback and leading-question bias addressed.
- [ ] Run the two-week pilot and report all outcomes, including failures.

## Working product and user path — 20%

- [x] Deployed product and source linked.
- [x] End-to-end judged-demo path documented.
- [x] Real versus modeled functions disclosed.
- [ ] Record a backup product walkthrough.
- [ ] Test the demo from a clean phone and laptop immediately before presenting.

## Venture economics — 15%

- [x] Payer, price, revenue mechanism, costs, CAC, and payback modeled.
- [x] Bear/base/bull sensitivity included.
- [x] Assumptions labeled rather than stated as traction.
- [ ] Replace modeled venue CAC and redemption rate with pilot data.
- [ ] Obtain paid pilots or letters of intent from venue decision-makers.

## User evidence and revision — 15%

- [x] Initial thesis and revised thesis clearly contrasted.
- [x] Feedback is linked to concrete product changes.
- [x] Evidence limitations are explicit.
- [ ] Enter exact participant count, dates, recruitment source, and demographics.
- [ ] Insert at least three real verbatim quotes, including one skeptical quote.
- [ ] Link anonymized raw notes or recordings.

## Build process, candor, ownership — 15%

- [x] Architecture, iteration sequence, deployed status, and limitations documented.
- [x] AI assistance disclosure drafted.
- [x] Next engineering gates prioritized.
- [ ] Replace ownership placeholders with actual names and contributions.
- [ ] Each team member rehearses the decisions and artifacts they own.
- [ ] Confirm that the disclosure exactly matches the tools and process used.

## Presentation package

- [x] Rubric narrative.
- [x] Browser/print pitch deck.
- [x] 90-second and five-minute demo scripts.
- [x] Experiment plan and interview guides.
- [x] Economics model and evidence log.
- [ ] Export the deck to PDF if required by the course platform.
- [ ] Remove all remaining bracketed placeholders before final submission.
